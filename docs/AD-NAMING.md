# มาตรฐานชื่อแอด — 1 หน้า

> ใช้กับทุกบัญชี ทุกสินค้า · เริ่มใช้ 10 ส.ค. 69
> **ของเดิมไม่ต้องรื้อทั้งกระดาน** — แก้เฉพาะตัวที่ dashboard ขึ้นแผง 🏷️ "แอดที่ตั้งชื่อไม่ครบ"

---

## รูปแบบ

```
กลุ่ม / กลุ่มเป้าหมาย / [วัตถุประสงค์] / [สินค้า] / งบ / วันที่
```

ช่องที่ **บังคับ** คือช่องที่ 2 = **กลุ่มเป้าหมาย** (ยิงใส่ใคร)
ที่เหลือใส่เท่าที่มี ตามที่เคยเขียนกันอยู่แล้ว

```
ตัวอย่างเต็ม     AI/AW/ยอดขาย/1CC/600/28Jul
ตัวอย่างสั้น     GRD/AW/600/6Aug
```

**ทำไมช่องที่ 2 ต้องบังคับ** — `ยอดขาย / Buy / ซื้อ / msg / conv` คือ **วัตถุประสงค์**
บอกว่าสั่ง Meta ให้ไปหา *อะไร* แต่ไม่ได้บอกว่ายิงใส่ *ใคร*
ถ้าไม่มีช่องนี้ ระบบอ่านไม่ออกว่างบก้อนนั้นอยู่ชั้นไหนของ funnel → เทียบ ROAS รายชั้นไม่ได้

---

## คำที่ใช้ได้ในช่อง "กลุ่มเป้าหมาย" (ใช้คำอื่นระบบจะอ่านไม่ออก)

| คำ | หมายถึง | ชั้น |
|---|---|---|
| `AW` | ปล่อยกว้าง / Advantage+ ไม่ได้เลือกกลุ่ม | TOF |
| `LAL` · `LAL1-3%` · `LAL2-3%` | Lookalike จาก list ลูกค้า | TOF |
| `ExAll` · `Ex180` · `Exซื้อ` · `ExAI` | ตัดคนที่เคยมีปฏิสัมพันธ์ออก = ล่าคนใหม่ล้วน | TOF |
| `ENG` | แคมเปญส่วนร่วม → สนทนา ยิงกว้าง | TOF |
| `VIEW` | แอดยอดวิว ยิงกว้าง | TOF |
| `RE180` · `RE365` | retarget ย้อนหลัง > 90 วัน | MOF |
| `RE7` · `RE30` · `RE60` | retarget ย้อนหลัง ≤ 90 วัน (ร้อนที่สุด) | BOF |

**ผสมกันได้** — ใส่ RE ก่อน Ex เสมอ: `AI/RE180/Exซื้อ/Omni/600/8Jul` = ยิงคนอุ่น 180 วันแต่ตัดคนที่ซื้อแล้วออก
(ระบบอ่าน RE ก่อน → นับเป็น MOF ถูกต้อง)

**ไม่ใช่คำบอกกลุ่ม** (ใส่ได้ แต่ต้องมีคำข้างบนด้วย): `ยอดขาย` `Buy` `ซื้อ` `msg` `conv` `conversion` `หาคนซื้อ`

## ❌ ผิด 5 ตัวอย่าง — และแก้เป็นอะไร

```
❌ AI/ยอดขาย/1CC/600/28Jul       →  ✅ AI/AW/ยอดขาย/1CC/600/28Jul
❌ GRD/600/30/Jul                →  ✅ GRD/AW/600/30/Jul
❌ 1 Cut/Buy/600/29Jul           →  ✅ 1 Cut/AW/Buy/600/29Jul
❌ A2/ยอดขาย/600/24Jul           →  ✅ A2/AW/ยอดขาย/600/24Jul
❌ 1 cut ยอดขาย ซื้อ - 700 19JULY →  ✅ 1 cut/AW/ยอดขาย ซื้อ - 700 19JULY
```
ทั้ง 5 ตัวผิดข้อเดียวกัน: มีแต่ **วัตถุประสงค์** ไม่มี **กลุ่มเป้าหมาย**

## กติกาที่เข้ากันได้กับของเดิม

1. **แก้ให้น้อยที่สุด — แค่แทรกคำบอกกลุ่มเป็นช่องที่ 2** ของเดิมทั้งหมดอยู่ต่อได้
2. **ห้ามตั้งชื่อซ้ำกันในบัญชีเดียว** — ระบบรวมแถวตามชื่อ ชื่อซ้ำ = ข้อมูล 2 แอดถูกยำเป็นตัวเดียว
   (เพราะแบบนี้ dashboard จึงเสนอชื่อที่ *ไม่ทิ้งข้อความเดิม* แทนที่จะประกอบชื่อใหม่ทั้งหมด)
3. **ชื่อเดิมที่มี RE / LAL / AW / Ex / ENG / VIEW อยู่แล้ว ไม่ต้องแตะ** — ระบบอ่านออกอยู่แล้ว
4. **สะกดยังไงก็ได้** ตัวพิมพ์เล็ก/ใหญ่ไม่มีผล (`ai` `AI` `Ai` เหมือนกัน) เว้นวรรคหรือไม่เว้นก็ได้
5. **หาง `- สำเนา` / `Clone 2026-08-08 1013` ที่ Meta เติมเอง ปล่อยไว้** ระบบตัดออกให้เอง
6. **งบเขียนเป็นตัวเลขล้วน** (`600` ไม่ใช่ `600฿`) — ระบบเอาไปเช็คกติกาแอดมด (ใช้เกิน 30% ของงบวันแล้วยังไม่มีออเดอร์ = ปิด)
   ถ้าดันงบ ให้ต่อท้ายด้วย `>` เช่น `500 > 700` ระบบจะอ่านตัวหลังเป็นงบปัจจุบันและนับว่า "ดันงบมาแล้ว 1 รอบ"

## เช็คว่าตั้งชื่อถูกไหม

เปิด dashboard → แผง **🏷️ แอดที่ตั้งชื่อไม่ครบ**
ถ้าแอดของคุณไม่โผล่ในตารางนั้น = ชื่อผ่านแล้ว
ถ้าโผล่ → คอลัมน์ขวาสุดคือชื่อที่ควรเปลี่ยนเป็น กดปุ่ม **ก๊อป** แล้วไปวางใน Ads Manager ได้เลย

## เป้าหมายของทั้งหมดนี้

ตอนนี้ (10 ส.ค. 69) งบ **37%** อยู่ในแอดที่ชื่อไม่บอกกลุ่ม
→ ระบบยังนับให้เป็น TOF ตามค่าเริ่มต้น (เพราะยืนยันแล้วว่าตั้งเป็นปล่อยกว้าง)
แต่ **พิสูจน์จากชื่อไม่ได้** — ถ้าวันไหนมีคนตั้งเป็น retarget โดยไม่เขียนในชื่อ ตัวเลขรายชั้นจะเพี้ยนทันทีโดยไม่มีใครรู้

**ตั้งชื่อครบ = ตอบคำถามพวกนี้ได้ทันที**
- งบหาคนใหม่ vs งบตามคนอุ่น อย่างละกี่ %
- ชั้นไหนทำ ROAS ได้ดีที่สุด ควรเทงบไปทางไหน
- สินค้าไหนขาดชั้นไหน (เช่น มีคนซื้อ 143 ราย แต่ไม่มี LAL เลย = ทิ้งท่อคนใหม่ที่ถูกที่สุดไว้เฉย ๆ)
